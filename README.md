# farming

Agentic planning system for a commercial farming operation: weather projection,
input-cost forecasting (including geopolitical drivers), market and export outlook,
and profit-optimized crop planning.

Start with `docs/agentic-file-plan.md` for the full list of knowledge files, agents,
skills, and models this project is built from. `CLAUDE.md` describes how agents are
expected to work in this repository.
