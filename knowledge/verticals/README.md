# verticals

Soil-to-finished-product business lines. Each folder holds:

- `business-plan.md` — narrative plan following `business-plan-template.md`.
- `assumptions.csv` — every number the financial model uses, one row each, with unit,
  source and date. This is the single source of truth for the spreadsheet.
- `<vertical>-financial-model.xlsx` — generated by `scripts/build_vertical_model.py`
  from `assumptions.csv`. Never hand-edit; change the CSV and regenerate.

Regenerate all models: `python3 scripts/build_vertical_model.py --all`
Regenerate one: `python3 scripts/build_vertical_model.py knowledge/verticals/wheat-flour`
