# specialty crops

Crops that grow well in south-central Kansas but are outside the core rotation (wheat,
sorghum, corn, soybeans, sunflower, alfalfa, cotton) and the produce plots. One file per
crop following `specialty-crop-template.md`. Each file ends with a finished-products
analysis, and every product is one row in `data/processed/finished_products.csv` (schema
`data/reference/finished-products-schema.md`) so all crops and products rank in one
spreadsheet. `RANKING.md` holds the cross-crop ranking.

Default structure for any finished product: a separate LLC buys the raw crop from the
trust farm and processes off trust land (`knowledge/operations/family-trust-constraints.md`).
Labor at FAMILY $11/hr loaded and HIRED_SEASONAL $18/hr (`knowledge/finance/labor-rates.md`).
