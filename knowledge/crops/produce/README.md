# produce crops

One file per produce crop, following `produce-crop-template.md`. Each file carries a
cost-benefit analysis across the sales channels (chef-direct restaurants, grocery and
wholesale, farmers market and CSA) at FAMILY labor ($11/hr loaded) and HIRED_SEASONAL
labor ($18/hr loaded) per `knowledge/finance/labor-rates.md`, and appends one row per
crop and channel to `data/processed/produce_crop_economics.csv` for side-by-side
comparison in a spreadsheet.
